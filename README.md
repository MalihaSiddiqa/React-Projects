# React Projects 🚀

A collection of interactive React applications and mini-projects exploring core hooks, state management, modern UI design, and frontend development. Perfect for beginners looking to escape tutorial hell and build a strong portfolio for front-end developer roles.

---

## 📂 Projects Included

| Project Name | Description & Key Concepts Learned | Live Demo |
| :--- | :--- | :--- |
| **Expense Tracker** | Track income and expenses dynamically with real-time balance calculations. 
| **Password Generator** | Secure, customizable password generator utilizing state management and clipboard APIs. 
| **Product Card** | Clean, responsive product component showcasing layout styling and modern UI principles.
| **Profile Builder** | Dynamic multi-section profile generator allowing users to create, edit, and preview profiles with browser storage. 
| **Quiz App** | Interactive quiz interface handling state transitions, scorekeeping, and question logic.
| **Quote Generator** | Random quote generator built with asynchronous API fetching and clean UI states. 
| **Recipe Finder** | Recipe search application featuring API data retrieval, filtering, and rich card layouts.
| **Maze Game** | Interactive 10x10 maze game featuring dynamic grid mapping and conditional status overlays.
| **Dog Profile Card** | Simple and expressive component showcasing props and reusable design patterns. 

---

## 🛠️ Tech Stack & Tools

* **Frontend:** React.js, HTML5, CSS3, JavaScript (ES6+)
* **Styling:** Tailwind CSS / Modern CSS
* **Build Tool:** Vite / Create React App
* **Deployment:** Render, Vercel

## 🚀 Getting Started Locally

To run any of these projects locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/MalihaSiddiqa/React-Projects.git](https://github.com/MalihaSiddiqa/React-Projects.git)

2. Navigate into a specific project directory:
   cd React-Projects/<Project-Folder-Name>

3. Install dependencies:
   npm install

💡 Why These Projects?
Building single-purpose, practical apps is the fastest way to understand core React concepts (like useState, useEffect, event handling, and component modularity). Feel free to explore, clone, and add these projects to your own frontend developer resume!
